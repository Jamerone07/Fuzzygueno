📋 Quick Setup Instructions

If you see errors above:

  1. Install XAMPP (includes PHP + Apache)
    • Download: https://www.apachefriends.org/
    • Copy project to: C:\xampp\htdocs\fuzzygueno\
    • Start Apache from XAMPP Control Panel
    • Access: http://localhost/fuzzygueno/
  2. OR Install PHP Standalone
    • Download: https://windows.php.net/download/
    • Extract to C:\php\
    • Add to PATH, then run: php -S localhost:8000

Important: Always access via http://localhost NOT file:///
