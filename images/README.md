# Images Folder

Place your product images and logo in this folder with the following names:

## Required Images:

1. **logo-placeholder.png** - Your Fuzzygueño logo (replace this placeholder)

2. **product-single-stem-placeholder.png** - Image for Single Stem Fuzzywire Flower

3. **product-standard-bouquet-placeholder.png** - Image for Standard Bouquet

4. **product-big-bouquet-placeholder.png** - Image for Big Bouquet

5. **product-keychains-placeholder.png** - Image for Custom Keychains

## Image Recommendations:

- Recommended size: 800x600px or larger
- Format: PNG or JPG
- Keep file sizes reasonable for web (under 500KB each)
- Use consistent styling/backgrounds for a cohesive look
